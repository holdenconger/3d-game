# 3D PC / Laptop Builder

This project is a 3D PC and laptop building game built with React + TypeScript
and `@react-three/fiber`.

## Quick start (CodeSandbox)
- Template: **React (TS)** by CodeSandbox
- Copy the `package.json`, `public/index.html`, and `src/` files from this repo
  into the sandbox.

## Features
- Guided or free-build part installation
- 3D scene with orbit controls
- Power, LED, and cooling controls
